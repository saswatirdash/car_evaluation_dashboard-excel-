# Car Evaluation Dashboard – Excel

## Project Overview

This project presents an interactive **Car Evaluation Dashboard developed using Microsoft Excel**. The dashboard converts the Car Evaluation dataset into easy-to-understand charts, summaries, and key insights.

## Problem Statement

Analyzing raw car evaluation data manually can make it difficult to compare vehicle characteristics and identify trends. The dashboard provides a visual and interactive way to explore the dataset.

## Objective

* Clean and organize the car evaluation dataset.
* Perform data analysis using Excel.
* Create meaningful visualizations.
* Present important evaluation patterns through a dashboard.
* Make the analysis easy to understand and explore.

## Technologies Used

* Microsoft Excel
* Excel formulas
* Pivot Tables
* Pivot Charts
* Data Cleaning
* Dashboard Visualization

## Key Features

* Interactive dashboard layout.
* Summary of car evaluation categories.
* Analysis of buying and maintenance costs.
* Comparison of safety and capacity-related attributes.
* Charts for identifying trends and distributions.
* Easy-to-use visual representation of the dataset.

## Outcome

The Excel dashboard provides a clear visual summary of car evaluations and allows users to understand patterns in the dataset without manually analyzing individual records.
